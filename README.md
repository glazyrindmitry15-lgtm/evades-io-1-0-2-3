# Evades.io 1.0 Multiplayer

Онлайн-версия игры с:
- мультиплеером (другие игроки видны в реальном времени),
- общим чатом,
- лидербордом,
- админ-командой `/cmd update liderbord`.

## Локальный запуск

```bash
npm install
npm start
```

Открыть: `http://localhost:8080`

## Деплой на Render (не через ваш ПК)

1. Загрузите проект в GitHub (новый репозиторий).
2. Зайдите на [Render](https://render.com/) и нажмите **New + -> Blueprint**.
3. Выберите ваш GitHub-репозиторий.
4. Render автоматически прочитает `render.yaml` и создаст сервис.
5. После деплоя получите публичный URL вида `https://your-app.onrender.com`.

## Команды в игре

- `/cmd admin 123` — вход в админку.
- `/cmd update liderbord` — принудительно обновить лидерборд.
- `/name Ник` — сменить имя в мультиплеере.

## Короны топ-3

- 1 место: платиновая корона
- 2 место: серебряная корона
- 3 место: бронзовая корона
